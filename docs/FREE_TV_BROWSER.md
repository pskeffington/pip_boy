# Rust-Boy Free TV browser navigation

Route: /free-tv. The page is self-contained and bounded to the viewport, with Pluto selected by default. Switching service changes the official HTTPS navigation target, not a hidden iframe source. Buttons are regular browser links opened only on user action; browser Back returns to the Rust-Boy interface.

The user can visit free public services in their normal browser, including Pluto, Plex, Roku, Tubi and Samsung TV Plus. There is NO embedded commercial player, network proxy, hidden API, DRM circumvention or copied media; this route does not claim an in-app video decoder.

Pluto's published terms at https://legal.paramount.com/us/en/plutotv/terms-of-use include specific restrictions on embedding the player into applications. Free service/open-source software do not independently confer embedding rights. Use official browser navigation unless vendor authorization or a documented permitted integration is established.

Handheld: <=900x520 outer shell, viewport-height layout, no media tile overflow. Desktop: FREE TV masthead link. Micro: FREE TV action on role tool page. Browser navigation is intentionally explicit.
